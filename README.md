# agentic-hr
Autonomous Agentic HR &amp; Recruitment platform built with NestJS, FastAPI, Next.js 14, and Groq (Llama-3.3 &amp; Whisper-v3). Features sub-second semantic ATS screening, automated deadline cutoff predictions, timed dynamic exams, real-time AI webcam interviews, and GDPR-grade cascading data purges.
