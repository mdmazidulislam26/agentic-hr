Key Architectural Challenges Solved

Thundering Herd Prevention

Avoided catastrophic database lockups during concurrent exam starts by staggering applicant arrivals into a 10-minute queue, shifting unlocking logic into browser client state.

Zero-Junk Retention Policy

Unqualified applicants (< 75%) are evaluated and rejected purely in-memory using PyMuPDF and Groq. Zero disk or persistent database writes occur, cutting cloud costs by 80%.

GDPR Cascading Purge

Implemented verified one-click hard purging using PostgreSQL ON DELETE CASCADE, permanently wiping transient audio, transcripts, and telemetry post-hire.
